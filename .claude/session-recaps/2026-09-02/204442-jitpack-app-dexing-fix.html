The fix

jitpack.yml

›

:app has no maven-publish plugin and is never part of what a consumer resolves — confirmed by the build log's own "Publication:" lines, which name exactly the 9 other modules, never :app. But JitPack's default command runs root-level assemble, which Gradle spreads across every subproject including :app, forcing a full demo-app dex that blows the container's disk quota.

install:
  - ./gradlew clean -Pgroup=$GROUP -Pversion=$VERSION -xtest -xlint assemble publishToMavenLocal -x :app:assemble

Added -x :app:assemble to JitPack's own default command. Nothing else changed — no BouncyCastle version bump, no minSdk change, no sample-app dependency removed.
